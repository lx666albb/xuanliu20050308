# 习题 6.1—6.3：MATLAB 绘图程序

对应教材第 107 页的三道题：

- 6.1 绘制图 6.7：网络规模 \(N\) 与平均搜索步数 \(T\) 的关系（\(K=5,\ p=0.2\)）
- 6.2 绘制图 6.8：平均搜索步数 \(T\) 与重连概率 \(p\) 的关系（\(N=200\)、\(N=100\)）
- 6.3 绘制图 6.9：\(k\) 遍历器搜索效率比较（\(k=1,2,4,8\)）

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `ex6_1.m` | 图 6.7，双对数坐标，URW / NRRW / SARW 三条曲线 |
| `ex6_2.m` | 图 6.8，左右两个子图，分别为 \(N=200\) 和 \(N=100\) |
| `ex6_3.m` | 图 6.9，线性坐标，\(k=1,2,4,8\) 四条曲线 |
| `cn_font.m` | 按操作系统返回可用的中文字体名，避免中文显示成方框 |
| `run_all.m` | 一次运行上面三个程序 |

## 运行方法

在 MATLAB 中把当前文件夹切换到本目录，然后任选一种：

```matlab
run_all
```

或单独运行：

```matlab
ex6_1
ex6_2
ex6_3
```

每个程序都会在当前目录生成：

- `fig6_7.png` / `fig6_8.png` / `fig6_9.png`（300 dpi）
- `fig6_7.fig` / `fig6_8.fig` / `fig6_9.fig`（可在 MATLAB 中继续编辑）

## 关于数据

教材只给出了曲线图，没有附原始数据表。程序第 1 节中的数组是**按图中标记点的位置读取并换算**得到的，保留到能复现图形所需的精度；个别点与原始仿真值可能有约 2%—3% 的误差。

这样处理的好处是：运行程序后得到的图形与书上基本一致，适合作为“画出图 6.7/6.8/6.9”的作业。若老师要求必须由模型仿真生成数据，只需把每个文件第 1 节的 `N`、`p`、`T_*` 数组替换为仿真输出，后面的绘图、坐标轴、图例和导出部分完全不用改。

## 中文显示说明

本目录中的 `.m` 文件按 UTF-8 保存。MATLAB R2020a 及更高版本默认使用 UTF-8，直接运行即可正常显示中文。

如果使用更早的 MATLAB，且坐标轴中文显示为乱码或方框，请用记事本或 VS Code 将文件“另存为” `ANSI`（简体中文 Windows 下即 GBK）编码后再运行。也可以把 `cn_font.m` 中的 `SimSun` 改成自己系统已安装的中文字体名。

## 图形设置说明

- 图 6.7、6.8 用 `loglog`，图 6.9 用 `plot`。
- 曲线统一为黑色实线、空心标记，与教材风格一致。
- 图 6.7 的标记：URW 方块、NRRW 三角、SARW 圆点。
- 图 6.9 的标记：\(k=1\) 方块、\(k=2\) 三角、\(k=4\) 圆点、\(k=8\) 五角星。
- 坐标轴刻度朝内，并打开次刻度；图例带边框。
- 中文字体由 `cn_font.m` 自动选择：Windows 用宋体，macOS 用宋体，Linux 用 Noto Sans CJK。

## 可调参数

如果想让图更接近自己的仿真结果，可以修改：

- `ex6_1.m` 中的 `N`、`T_URW`、`T_NRRW`、`T_SARW`；
- `ex6_2.m` 中的 `p` 及六组 `T_*`；
- `ex6_3.m` 中的 `N`、`T_k1`、`T_k2`、`T_k4`、`T_k8`；
- 各文件的 `XLim`、`YLim`、`XTick`、`YTick` 可调整坐标范围；
- `print(..., '-r300')` 中的 `300` 可改为其他分辨率。
